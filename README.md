# Portfólio — Luan Dionísio Martinho

Site estático, responsivo e sem etapa de build.

## Antes de publicar
- Em `index.html`, troque `SEU_EMAIL_AQUI` pelo seu e-mail.
- Troque o link `https://www.linkedin.com/` pela URL do seu LinkedIn.
- Confirme com a UNIFEBE se as fotos de eventos podem ser publicadas.
- Se necessário, substitua as fotos em `assets/` por versões autorizadas.

## Publicar
### GitHub Pages
Crie um repositório, envie os arquivos e ative Settings → Pages → branch principal → `/root`.
### Netlify
Arraste a pasta para o Netlify Drop ou conecte um repositório GitHub.
### Vercel
Importe o repositório como projeto estático.
